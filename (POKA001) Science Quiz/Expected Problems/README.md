# Expected Problems

This folder contains the standalone collection of expected mathematics problems
for Science Quiz. It is a companion to `Mathematics for Science Quiz` and is
maintained as a continuously updated problem collection rather than as a numbered
edition.

The document is written in English and follows the notation and mathematical
writing conventions of the latest `(MATH000) Mathematical Language` on the
GitHub `main` branch at the time of this revision.

## Folder Structure

- `ExpectedProblems.tex`: main document
- `ExpectedProblemsStyle.sty`: shared formatting and mathematical notation
- `Sections/`: the five problem sections
- `Figures/`: editable figure sources, shared figure styles, and compiled figures
- `ExpectedProblems.pdf`: compiled problem collection
- `ExpectedProblems.synctex.gz`: source synchronization data

## Organization

Problems and their solutions remain adjacent. Numbering restarts from 1 in each
of the following sections:

1. Standard Mathematical Problems
2. Direct Calculation Problems
3. Memorization Problems
4. Reasoning and Puzzle Problems
5. Mathematical Intuition Problems

Optional problem headings preserve the compact `[Source, Name]` convention used
in the companion handbook.
