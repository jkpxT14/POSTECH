# v4.0 Final Editorial Pass

Edition date: **2026-09-17**

v4.0은 최신 GitHub `Final Review`를 기준으로, 경기 직전 사용할 최종판의 언어·내용·형식을 전수 정리한 판입니다. 목표는 약 3시간 1회독이 가능한 밀도를 유지하면서 필요한 내용을 누락하지 않고 군더더기와 중복을 제거하는 것입니다.

## 주요 수정

- 본교재의 Part / Chapter / Section 흐름을 기준으로 Part I-III 구조를 정리하고 불필요한 소제목을 만들지 않았습니다.
- 최신 MATH000과 표기를 전수 대조하여 행렬·벡터, 선형대수 연산자, Jacobian/Hessian, 확률, 복소해석, 위상수학 표기를 통일했습니다.
- Part I에 적분, 수열·급수, 극한·함수열, 복소해석, 행렬식, 고유값·고유벡터, 행렬의 계수, 미분방정식, 경우의 수, 확률, 기하, 정수론, 대수, 위상 문제의 짧은 문제 인식 흐름을 추가했습니다. 별도의 새 Chapter나 Section은 만들지 않았습니다.
- 단순 목록·연표를 억지로 Fact/Formula로 감싸던 부분과 중복 설명을 정리하고, theorem-like environment는 실제 의미가 있을 때만 사용했습니다.
- Part II는 상의 수상연도, 수학자의 출생연도, 기관의 설립연도, 수학사의 사건연도, 저작의 발표연도, 일화의 사건연도를 기본 순서로 정리했습니다.
- 필즈상 개최지는 도시와 국가를 함께 표시하고, 필즈상·아벨상과 마찬가지로 울프 수학상도 전체 수상 연표를 수록했습니다.
- 수학 기호의 역사, 수 체계의 발전, 최석정과 《구수략》, NIMS와 IBS-CGP, 주요 문헌, 힐베르트 문제와 밀레니엄 문제의 식별 단서 등 압축 과정에서 지나치게 빠졌던 암기 소재를 짧게 복구했습니다.
- `유명한 역설과 암호`처럼 서로 다른 범주를 억지로 묶던 구성을 해체하고, 유명한 수학적 역설은 별도의 간결한 목록으로 정리했습니다.
- Part III의 편집자용 표현과 영어 메모 문체를 제거하고 한국어 중심으로 정리했으며, 동일 사실을 표와 Fact에서 반복하던 부분을 줄였습니다.
- Part IV의 지정 35문항을 모두 다시 검토했습니다. 현재 풀이보다 더 직접적이거나 엄밀하거나 기억하기 좋은 경우 풀이를 교체하고, 좋은 기존 풀이는 유지했습니다. 특히 2023.4의 극한 논리, 2025.3의 구의 접촉 조건, 2025.17의 최초 등장 순서 해설을 정리했습니다.
- theorem-like heading 직후 목록이 와서 첫 bullet이 제목과 같은 줄에 붙는 조판 문제를 제거하고, 페이지 나눔·표·수식·여백을 다시 점검했습니다.
- 첫 페이지의 불필요한 제작 설명 문구는 제거했습니다.
